# Glossary

The terms used across code, copy and docs.

| Term | Meaning | Example |
|---|---|---|
| **topic** | What a puzzle is about, identified by its tidied name. | Roman History |
| **difficulty** | `normal` or `expert`. | Expert |
| **series** | A topic at one difficulty. Pools, thresholds and lifecycle states (available, winding down, finished) belong to a series. Mostly internal; players see the topic and the difficulty. | Roman History, Expert |
| **puzzle** | A series' daily instance, with one secret answer shared by everyone who plays it that day. | Roman History, Expert, 2026-10-12 |
| **game** | One player's attempt at a puzzle: their questions, hints and result. Each game has its own share code for its replay. | Alice's game of that puzzle |
| **answer** | A puzzle's secret. Also what a pool holds and what the topic preview shows samples of. | The Battle of Philippi |
| **pool** | A series' stock of unused answers, from which each new puzzle draws one. | |
| **preview** | Five representative answers set aside when a topic is built, shown to players to convey the topic's range, never used as puzzles. | |
| **replay** | Viewing a finished game, reached through its share code. | |

Seasons (a finished series relaunching as "Season 2") are a future idea; the term is reserved for that.
